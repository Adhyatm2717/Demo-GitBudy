# Demo Project

A simple demo project used to showcase **GitBuddy** — a beginner-friendly Git CLI assistant built to make everyday Git operations easier.

## 🚀 Pushed Using GitBuddy

All project files in this repository were pushed using **GitBuddy**, an npm package that simplifies Git workflows through an interactive command-line interface.

Instead of remembering multiple Git commands, GitBuddy guides you through the process of staging, committing, and pushing your changes.

## 📦 Try GitBuddy

You can install GitBuddy directly from npm:

```bash
npm i github-buddy
```

For global installation (recommended for CLI usage):

```bash
npm install -g github-buddy
```

Start GitBuddy:

```bash
buddy
```

## ✨ Available Commands

| Command | Description |
|---|---|
| `buddy` | Open the interactive menu |
| `buddy status` | View Git status |
| `buddy push` | Stage, commit, and push changes |
| `buddy pull` | Pull latest changes |
| `buddy save` | Create a commit |
| `buddy branch` | Manage branches |
| `buddy history` | View recent commits |
| `buddy undo` | Guided undo operations |
| `buddy sync` | Pull and push your branch |
| `buddy help` | View help information |
